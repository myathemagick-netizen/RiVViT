## Conventions

- **Small, targeted edits.** Changes are described by location (section header + exact line) so they can be made directly in the GitHub editor.
- **Test on three surfaces** before calling a feature done: desktop Chrome, a phone browser, and Meta Quest 3.
- **New layers default to off**, like the Australian Songlines overlay, and get a toggle in both the web menu and the VR menu.
- **Geometry is load-bearing.** The 12-node Sanderson belt layout and its 30 edges underpin every derived layer. Change node coordinates deliberately and note it in the changelog.
