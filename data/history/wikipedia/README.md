# Imported Wikipedia chronology data

These JSON files contain extracted/adapted English Wikipedia chronology text and research metadata. **License: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Attribution: Wikipedia contributors.** Each yearly file's `pages` records article URLs, revision permalinks, contributor-history links, retrieval information and content hashes. The `license.changes` field identifies transformations. Preserve attribution and licensing when sharing these data or adapted text.

`1961.json` is the normalized collection; `1961-candidates.json` is a filtered, unreviewed suggestion queue. `index.json` summarizes coverage. These files are not loaded into RiVViT yet. No coordinates are asserted and entries are not individually fact-checked. See [workflow, counts, caveats and commands](../../../doc/WIKIPEDIA-HISTORY.md).
